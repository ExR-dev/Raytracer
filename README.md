# Raytracer
 A GLSL-based raytracer rendered with SFML 3.0.2. 
 The lighting model supports emission, reflection & refraction, gloss, absorption and more. 
 The renderer also supports cumulative rendering and many other small features. 
 Multiple primitives are supported including triangles. Importing meshes is not supported.
